模型 Provider 配置

模型审查需要复核。配置好 Provider 后，语义结论会自动纳入本次审查的证据链与评分，但仍受 Provider 可用性、样本覆盖和证据质量影响；高风险结论请结合原文定位复查。未配置 Provider 时会如实提示未配置，不影响静态检查结果。

可选：添加最多两个额外校验模型，多个校验模型会对同一候选各自投票，按多数结果判定；只配置一个校验模型时行为与之前完全一致。

不会发送完整原文、绝对路径或 RedactionMap；语义审查固定使用脱敏证据片段。API Key 只保存在当前 macOS 用户的钥匙串中。
